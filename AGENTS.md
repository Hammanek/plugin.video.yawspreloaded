# Project Instructions

## Release checklist

`README.md` must be updated with every release. Before creating a Git tag or publishing a GitHub release:

1. Update the README version badge so it exactly matches the `version` attribute in `addon.xml`.
2. Review and update the feature descriptions so they reflect all user-visible changes since the previous release.
3. Review and update the setup and installation instructions, including the latest-release link and installation ZIP guidance.
4. Include the README update in the release preparation commit; do not tag or publish until these checks are complete.
5. After publishing, verify that the release targets the intended commit and that the installation archive is attached.

A release is incomplete while README version information, features, setup instructions, or installation instructions are stale.
